# Cidade 3D v2 (maquete noturna) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Re-skin visual da `/cidade` para low-poly polido estilo bruno-simon em versão metrópole noturna (kits Kenney CC0 + sombras/AO + letreiros físicos animados), preservando 100% dos sistemas v1.

**Architecture:** Assets GLB curados em `public/models/city/` com manifest em `src/components/city/assets.ts`; retintagem central por override de materiais; `CityBuildings`/`CityStreets` reescritos sobre os modelos; novo `CityAtmosphere` (céu/luz/AO) e `SignBoard` (letreiros). `places.ts`, `CityPage`, `CameraRig`, `CityLife` (avatar/trem/eggs) e `cityAudio` intactos salvo integrações mínimas.

**Tech Stack:** react-three-fiber v8, drei (useGLTF, Instances, Text), @react-three/postprocessing (Bloom, N8AO), kits Kenney CC0.

**Spec:** `docs/superpowers/specs/2026-08-25-cidade-v2-maquete-noturna-design.md`

## Global Constraints

- React 18 → fiber v8/drei v9 apenas; sem dependências novas de npm.
- Sistemas v1 INVARIANTES: places.ts (posições/waypoints/frames), CityPage (cards/HUD/relógio/som), CameraRig, avatar procedural, trem elevado, cityAudio, i18n, SEO. Qualquer task que precise tocá-los faz a mínima integração e declara no report.
- Assets: somente kenney.nl (CC0). Total em `public/models/city/` ≤ 12MB. Nenhum outro download externo.
- Sombras + N8AO: desktop e !reducedMotion apenas. Mobile mantém pipeline leve (DPR ≤1.5, metade das variações, sem AO/sombra).
- reducedMotion congela toda animação nova (letreiros acesos fixos, marquee off). Fotossensibilidade: nada acima de ~3 flashes/s em área de tela.
- Todo mesh decorativo `raycast={() => null}`; POIs clicáveis mantêm handlers + guard `e.delta > 4`.
- Paleta noturna: céu `#0b1026`→`#1a2547`, fog azulada, materiais foscos (roughness ≥0.8, metalness 0), janelas quentes `#ffd9a0`, neon `#1fb2aa` só em letreiros/antena.
- Verificação por task: `npm run lint` (pré-existentes em ui/command.tsx, ui/textarea.tsx, FloatingShapesLayer.tsx, main.tsx não contam) + `npm run build`; visual = controller no browser.
- Commits PT conventional (escopo `cidade-v2`) + footer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`. Branch `qa`.
